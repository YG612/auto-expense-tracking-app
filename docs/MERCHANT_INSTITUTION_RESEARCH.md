# 常见商户机构规则调研

调研日期：2026-08-14。

## 目标与原则

本规则集用于本机文字记账、微信/支付宝官方账单导入和 Android 支付通知候选。它识别品牌名及账单中常见的法定主体名，再映射到已有稳定分类；不联网查询商户，不上传账单，也不根据公司名称创建新分类。

规则只直接分类“主营业务与账本分类高度一致”的机构。淘宝、京东、拼多多、美团综合平台、商场、超市和便利店能销售多类商品，因此不因品牌本身新增强制分类。用户创建的规则和经可靠纠正形成的本地商户规则始终优先。

## 防误判边界

- 餐饮品牌出现在“速冻、预制、调料、代金券、礼品卡、会员卡、股票、周边”等上下文时，不按餐厅消费处理。
- “中国石油大学”不会被识别为加油消费。
- 综合零售、便利店和平台品牌不新增直接分类；需要商品名、用户规则或后续人工确认。
- 只为支出应用机构默认分类；退款、收入、转账等仍受交易类型与分类方向一致性检查约束。

实现和维护入口：`src/classification/rules/merchantInstitutionRules.ts`。新增规则必须提供至少一个正例、一个可能冲突的反例，并通过完整分类与导入测试。
