# Android 真机重点回归

这套流程用于验证 Internal APK 的安装后行为，不用模拟器、不创建录音、不导出账本，也不抓取全量 `logcat`。自动化只能证明设备连接、应用进程、权限事实和系统语音组件；语义结果与交互仍必须由测试人员在屏幕上验收，不能据此宣称所有 Android 手机均已通过。

## 1. 安装

先连接一台已开启 USB 调试并完成电脑授权的真机，然后运行项目统一安装器：

```powershell
pnpm android:install:internal:windows
```

安装器只使用 `adb install -r`，保留应用数据。签名不一致、版本降级或 ABI 不兼容时会停止，不会自动卸载、清空数据或强制降级。连接多台设备时使用 `-DeviceSerial` 直接调用安装脚本指定目标；序列号不得复制进缺陷报告。

## 2. 启动并收集脱敏预检证据

```powershell
pnpm android:regression:device:windows
```

需要在连接多台设备时指定目标，可直接运行脚本并传入 `-DeviceSerial`。

结果只写入 `D:\CodexData\TestEvidence\QingJiAI\<时间戳>`，包含：

- 厂商、型号、Android/API、ABI 和非唯一构建 ID；
- Internal 是否安装、启动后三秒进程是否存在；
- `RECORD_AUDIO` 权限和 AppOps 的规范化状态；
- 默认语音识别组件、可查询的识别服务与系统识别 Activity；
- 只含时间、reason/status/importance 的应用退出元数据；
- 一份全部为 `NOT_RUN` 的人工回归清单。

证据明确不包含 ADB 序列号、录音、转写正文、账本正文、全量日志、屏幕录制或其他应用列表。`APP_RUNNING=true` 只能证明采样时进程存在，不能替代崩溃和功能验收。

## 3. 必测场景

使用脚本生成的 `manual-regression-checklist.md` 逐项执行。只使用固定合成数据，不使用真实工资、商户、账户或地址：

1. “今天下午去商场买两瓶牛奶然后花了25元”：恰好一张支出卡，金额 25 元，食品杂货分类；“两瓶”不是第二笔或 2 元。
2. “工资8000元到账”：恰好一张收入/工资卡，金额 8000 元。
3. 编辑并确认成功：卡片只消失一次，流水只新增一次。
4. 权限设置返回：只重新检测，不自动录音、不自动联网。
5. 本地模型下载：必须由用户显式触发；下载中不能开始录音；就绪后重新检测可用。
6. “充值100元”等不确定输入：没有“确认入账”，只能检查编辑或暂存。
7. App 权限已开、系统全局麦克风关闭：必须识别为隐私开关问题，不能误报未授权。
8. 取消系统语音、快速双击开始：没有重复卡片、永久 busy、崩溃或静默联网。
9. “今天在网吧消费10元，微信付的”：一张娱乐支出卡，10 元；字段完整时卡片外直接显示“确认入账”。
10. 场所不能覆盖明确对象：“在网吧买水3元”归餐饮/饮料；“在网吧买鼠标80元”归购物/数码。
11. “买5瓶牛奶每瓶10元，微信付的”：只有一张 50 元卡，不能把 5 或 10 当总金额。
12. 储值和押金保持安全降级：“网吧充值100元”“交网吧押金100元”不得直接确认；“网吧退给我10元”保持退款语义。
13. 个人规则同时指定“坐车→交通”和“微信”后，“坐车来回花了4元”应在卡片外一键确认，不强迫进入编辑页。
14. 确认幂等：单击或快速双击都只新增一笔、只移除一次卡片。
15. “网吧上网10元，然后买泡面5元，微信付的”：两张卡分别为娱乐 10 元、餐饮 5 元，金额和分类不能串联。
16. 长句自然停顿：系统 Provider 若提前结束，必须保留已有文字并提供“继续说/使用这段文字”；续说只能追加，不能覆盖或产生重复卡片。
17. 支付通知默认关闭：仅授予系统通知使用权、未开启 App 内开关时，微信/支付宝支付不得生成待确认账。
18. 开启支付通知后分别验证微信消费、支付宝消费、收款、退款与转账；金额、方向、渠道和时间正确，且只自动生成一条待确认记录。
19. App 被划掉或受省电限制时完成支付，重新打开 App 后应自动补导；重复打开、重复通知和“落库后确认前强杀”都不能重复入账。
20. 普通微信聊天包含“付款成功 100 元”时不得触发；关闭开关后队列清零，后续支付不得继续捕获。

语音转写本身由系统 Provider 决定，因此同一语义场景还应直接走文字输入复测。文字通过但语音失败时，应记录 route、稳定错误标签与设备能力事实，不能把 Provider 问题归为解析器问题。

1.0.5 轻量包不内置语音模型。如果设备没有可下载的系统普通话包，第 5 项记为 `N/A`，不能记为通过。Google 或其他系统 Activity 的自动收音终止由 Provider 控制；本版通过“继续说/使用这段文字”避免丢失内容，但只有 App 自持或内嵌收音路径才能保证由用户点击“说完了”后结束。

## 4. 失败证据

只记录场景 ID、屏幕状态、稳定错误标签、识别 route、耗时和必要的脱敏截图。截图前遮挡通知、联系人、账户、真实流水和设备序列号。禁止上传原始音频或完整转写日志。

真机没有连接时，脚本会停止；不会生成“通过”结果。人工清单默认全部 `NOT_RUN`，只有测试人员实际观察后才能改为通过或失败。
