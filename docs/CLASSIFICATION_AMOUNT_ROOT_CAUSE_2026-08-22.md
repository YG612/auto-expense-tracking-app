# “鲜花饼一块两元”金额与分类缺陷根因报告

日期：2026-08-22
状态：源码修复、自动回归和受控增量 APK 审计已完成；干净重建与真机复测仍是独立证据

## 1. 结论

用户观察到的现象不是单一分类模型错误，而是金额语法、候选资格策略和分类知识覆盖三层问题叠加：

1. 金额解析器把“块”只当作“元”的口语单位，没有同时建模“块”作为数量量词的角色。
2. “一块”与“两元”因此被识别为两个金额；同优先级金额按文本顺序取第一个，界面显示了 `1.00`，同时留下多个金额歧义。
3. 端侧分类器的资格门原先拒绝所有带歧义的候选，包括与分类无关的金额歧义，所以模型没有机会补上餐饮分类。
4. 当前随包模型实际仍是 `0.1.0-bootstrap`，训练数据以模板和少量别名为主；“鲜花饼、月饼、蛋糕、青团”等糕点词族未进入高精度语义本体，兼容模型本身也没有真实盲测覆盖保证。

因此，问题既包含底层逻辑缺陷，也包含模型/知识覆盖不足。只给模型增加“鲜花饼”一个词不能解决“两块蛋糕花20元”“买一块蛋糕”等同类错金额；只修金额也不能解决其他常见食品漏分类。

## 3. 修复前复现

修复前，确定性解析器产生以下结果：

| 输入              | 错误结果 | 根因                               |
| ----------------- | -------: | ---------------------------------- |
| 嗯鲜花饼一块两元  |     1.00 | “一块”和“两元”均被视为金额，取前者 |
| 两块蛋糕花了20元  |     2.00 | “两块”被视为金额并先出现           |
| 买一块蛋糕        |     1.00 | 数量被直接写成金额                 |
| 买两块豆腐每块3元 | 无法推导 | “两块”不是数量，单位匹配失败       |
| 花了一块两毛      |     1.00 | “毛”未被识别为“角”的口语别名       |

食品覆盖审计还发现，“鲜花饼、月饼、蛋糕、绿豆糕、青团、麻薯、曲奇、包子、烧饼、寿司、汉堡”等常见商品在确定性层全部缺少分类。

## 4. 分层修复

### 4.1 金额层

- 将“块”纳入数量单位，但在货币、数量和计价单位三种角色之间做上下文判定。
- 支持“商品一块两元”“买一块商品两元”“两块商品四元”“每块3元”“3元一块”等前后置语序。
- 保留“早餐一块二”“花了两块钱”等口语金额。
- 增加“毛”作为“角”的口语别名。
- 对“豆腐两块”“买了两块”这类上下文不足的表达停止猜测金额。
- 多个不同金额且没有明确总价时，不再预填第一个金额，而是要求补充实付金额。

### 4.2 分类资格层

端侧模型现在可在“只有金额歧义”时继续提出分类建议，但金额仍保持缺失或歧义，确认策略仍为编辑后确认。任何未知歧义、分类歧义、特殊资金语义或候选分类冲突仍默认阻断模型。

这实现了字段职责隔离：金额不确定不能让模型猜金额，也不应无条件剥夺模型对商品分类的独立建议能力。

### 4.3 语义分类层

新增两个高精度商品概念族：

- 糕点点心：鲜花饼、月饼、蛋糕、绿豆糕、青团、麻薯、曲奇等，归一级“餐饮”。
- 即食餐点：包子、饺子、烧麦、寿司、汉堡、米线、炒饭、煎饼、肉夹馍等，归一级“餐饮”。

二级分类只保留给内部规则、模型与统计，用户界面仍只需选择一级分类。

券类作为排除上下文：食品名称出现在“代金券、优惠券、兑换券、餐券、礼券”中时，不使用食品商品规则；但明确的高优先级电商平台规则仍可保留，例如“淘宝买沙县小吃代金券”继续归购物，避免风险规则越级覆盖可靠证据。

## 5. 模型现状与边界

本次修复没有把 v3 实验权重冒充为已发布模型。当前 APK 的 `0.1.0-bootstrap` 仍只有模板化合成数据，保守阈值会产生较多弃权。v3 九标签候选虽已通过合成数据算法门禁，但尚未完成授权真实数据盲测、人工批准和 shadow 观察，不能直接提升为随包正式资产。

本次即时正确性来自：金额解析修复、高精度语义本体和更合理的模型资格隔离。后续模型完善仍需使用授权、去标识、按用户/商户隔离的真实语料重新训练与冻结评估，且模型始终不能负责金额、账户、特殊资金类型或自动写账。

`嗯鲜花饼一块两元` 的端到端候选应为：

- 类型：支出
