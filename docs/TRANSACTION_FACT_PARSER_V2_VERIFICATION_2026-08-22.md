1. 将动作词表下沉到无业务依赖的共享语言层，解析器、结算安全门禁和个性化学习使用同一版本化词源。

## 已验证行为

- `给老王发了67块`：金额 67 元、对象老王、对外转出、资金转移语义一致。
- `发 / 转 / 打 / 汇 / 付 / 支付` 与 `元 / 块 / 块钱` 的 18 种组合全字段一致。
- `转了67块给老王`：支持金额在动作之后、对象在金额之后的语序。
- `老王给我转了67块`：识别来款人与流入方向，但不臆测收入或借款类型。
- `给孩子交学费3000元`：孩子是受益人，不是商户；用途为学费。
- `从微信转到支付宝67块`：来源/目标账户分离，不生成商户。
- `借给 / 向…借 / 还… / …还我`：借贷方向和类型绑定同一对象与金额。
- `给老王发红包67块`：红包用途优先于通用转账语义。
- `买3块面包`：3 块保持数量，未被事实层强制当成金额。
- 计划、失败、取消、反事实和他人转述：不生成账目。
- `坐车花了45块钱，支付宝` 与 `去北京花了35块钱支付宝`：金额和账户正确，地点不成为商户。
- `老王给我转了67块，支付宝`：账户名中的“支付”不会再污染为支出类型。
